# D-062 生日主角海报实施卡

状态：开发中；00 唯一写入；本地开发，不推送或部署。

## 已批准范围

- Sender 五步保持不变。心意内容增加独立可选入口，两种 Memory 均可配置。
- 上传 → 自动抠图 → 检查边缘 → 模板选择 → 拖动、缩放、重置 → 确认。可取消、重试、换图、移除；失败不替换上次确认结果。模板不叠加生日帽，避免不同人物头型与裁切产生错误遮挡。
- 彩色原人物，不生成或重绘脸、不加年龄字段。未配置和旧作品保留 Tada。
- 气球派对：原彩色气球构图，无文字纸条，左下小礼盒与蓝星。
- 蓝色许愿：蓝白纸张、蜡笔、双星、礼物盒、银色星光、疏朗彩带和单支蜡烛缎带蛋糕。无帽、无年龄数字。
- 390×844 主验收；360–430px；两侧至少 24px，标题 28px，正文 16px，主按钮 52px，触控至少 44px，底部 safe-area。

## 实施顺序

1. 技术试验：浏览器 Worker + ONNX Runtime WASM + U²-Net small。同源静态模型，单线程，不依赖海外运行时 CDN。验证真实透明、取消、超时、空结果、失败重试及手机性能。此模型属于通用显著物体检测，不保证只有一个人，也不等同精细发丝 matting；质量不达标必须更换方案，不虚报完成。
2. 过程资产准备：将批准模板拆为纸底/后景、人物和前景。过程 PNG 不制作网页陈列，也不逐张交用户验收；用自动测试检查真实 alpha、尺寸、透明留白、空隙、来源和命名，只保留选定图层。生日帽不进入正式模板。
3. 完整模板合成：先完成气球派对，再完成蓝色许愿。两款共用固定几何和一个合成器；不能把示意人像烤进模板。每款只在完整合成后提供一张 390×844 成品给用户验收，检查安全边距、层级和视觉比例。
4. 新增独立可选 portrait 草稿：模板版本、去背景贴纸、人物位移与缩放；大 PNG 放入浏览器图片存储，普通草稿只保留轻量引用。完成合成后只将最终图用于 Receiver，旧草稿缺失字段合法；编辑失败不覆盖上次成功结果。
5. 接入真实 Sender 操作：上传、抠图、模板选择、拖动、缩放、重置、确认和失败恢复。此阶段提供可操作模块预览；照片在浏览器本地处理并剥离 EXIF，草稿容量不足明确提示。
6. 发布只上传已合成 PNG，复用私有媒体验证、归属、签名和撤回；原照片与中间抠图不进入公共响应。Receiver 5/5 优先显示成品海报，缺失时回退 Tada。
7. 两款完整编辑与发布回归通过后才刷新 3005。发布不可变快照，旧作品不被自动修改。

## 产物与验收分层

- 内部过程：模型、原始图集、抠图 PNG、遮罩和单层贴图。只做自动检查与来源记录，不制作展示网页。
- 视觉验收：每款模板的一张完整合成成品。用户只判断构图、风格、信息层级和安全边距。
- 功能验收：真实上传编辑模块。必须能操作、取消、重试、换图、恢复，不用静态素材页代替。
- 集成验收：Sender → 发布 → Receiver 5/5 完整闭环，最后才刷新 3005 统一预览。

## 验证与交付门槛

- 单测：像素归一化、alpha 与原透明度相乘、边界裁切、空/常量/非法 mask、变换限制、旧数据兼容。
- 浏览器：本地推理、无照片外发、真实透明边缘、取消后不回写、超时可恢复、换图失败保留上次结果、模板切换、人像拖动/缩放/重置、草稿重载恢复与键盘。
- 发布：Card/Scrapbook × 无/有海报；只最终图可读，跨设备签名显示，撤回后不可新取图，发布失败保留草稿。
- 视觉：与已批准稿对照，安全区实测，真实照片横竖比例、发丝/眼镜/衣服/复杂背景，不以截图渲染或 mock 输出代替抠图质量。
- 手机 Safari / 微信性能另做真机验收；当前服务器 2GB，避免把大模型直接塞入 Web 服务进程。
