# Ta-da! 互动生日惊喜 H5

Ta-da! 是一份可以被亲手制作、互动解锁和逐步拆开的生日礼物。

这个仓库包含作品 Demo 的完整前端代码，覆盖送礼人创作与收礼人接收两端的核心体验：

- 找礼物、剪刀石头布、吹蜡烛与直接送达
- 普通贺卡与回忆手帐
- 可选礼物领取链接
- 移动端优先的完整拆礼物流程

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000/create` 进入送礼人创作端。

## 作品 Demo 范围

当前公开版本使用本地示例数据，适合作品展示与手机体验。真实用户数据持久化、跨设备创建和独立分享链接不包含在本次 Demo 中。

## 技术栈

- Next.js
- React
- TypeScript
- Tailwind CSS
